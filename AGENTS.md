## Cursor Cloud specific instructions

`padopado` (파도파도) is a single client-side Next.js 16 / React 19 app (App Router, TypeScript, Tailwind v4). There is no backend, database, or auth — all domain data comes from local mock files in `src/data/`. Standard commands live in `README.md` / `package.json` (`npm run dev` on port 3000, `npm run lint`, `npm run build`).

Non-obvious notes:
- The Kakao Maps key (`NEXT_PUBLIC_KAKAO_MAP_APP_KEY`) is OPTIONAL for development. Without it the app runs fine and renders a fallback notice in the map area (`src/components/map/MapFallback.tsx`); the rest of the UI (categories, search, detail panel, tide summary) is fully interactive and testable. Only the live interactive Kakao map + markers require a valid key plus browser internet access to `dapi.kakao.com`.
